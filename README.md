# Theophilus Mukwevho - Portfolio

Welcome to my professional portfolio website! This responsive website showcases my skills, projects, and experience in the tech industry.

## Features

- Modern, responsive design that works on all devices
- Interactive elements and smooth animations
- Contact form with Formspree integration
- Newsletter subscription
- Downloadable CV
- Project showcase with detailed descriptions

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts
- Formspree (for form handling)

## Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Open `index.html` in your browser.

## Deployment

This website is deployed using GitHub Pages. Any changes pushed to the `main` branch will automatically deploy to:

https://your-username.github.io/your-repo-name/

## Form Setup

The contact form and newsletter are powered by Formspree. To set up your own forms:

1. Go to [Formspree](https://formspree.io/)
2. Create a free account
3. Create new forms for both contact and newsletter
4. Update the form actions in `index.html` with your Formspree form IDs
